# 仕入れ判定ノート（国内仕入れ→eBay販売支援）Phase 1

仕様書 v1.0（2026-11-03）の **Phase 1** を実装した、スマホ優先・端末内保存のWebアプリです。
外部API・AI・有料サービスなしで動きます。相場の自動取得はしていません。

## 技術選定と理由

| 項目 | 採用 | 理由 |
|---|---|---|
| 言語 | TypeScript | 仕様書の候補。金額・状態の型を厳密にするため |
| UI | Preact（Vite） | 軽量（本体 約50KB gzip）でスマホの初回表示が速い |
| 金額計算 | decimal.js | 浮動小数の誤差を避ける。内部精度40桁、表示時のみ円単位に丸め |
| 保存 | IndexedDB（idb） | 端末内保存・オフライン対応。サーバー不要 |
| バーコード | 標準 BarcodeDetector → なければ ZXing | iPhone Safari は BarcodeDetector 非対応のため ZXing を遅延読み込み |
| テスト | Vitest + fake-indexeddb、Playwright | 計算・コード・統計・保存の自動テストと画面操作の確認 |

## 起動方法

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # 自動テスト（47件）
npm run build      # dist/ に本番用ファイルを出力
npm run preview    # dist/ をローカル配信（http://localhost:4173）
```

### スマホ（iPhone）で使うには HTTPS が必要
カメラは HTTPS か localhost のページでしか動きません。PC の開発サーバーを LAN の IP（http://192.168.x.x）で開いても**カメラは動きません**（手入力・写真読み取りは使えます）。

`dist/` フォルダの中身を HTTPS の静的ホスティングに置いてください（例：GitHub Pages、Cloudflare Pages、Netlify。いずれも個人利用の範囲なら無料枠あり）。中身はすべて相対パスで、サーバー側の処理はありません。

### オフライン
初回に HTTPS で開くと、Service Worker が画面一式と読み取りライブラリを端末にキャッシュします。以後はオフラインでも、保存済みの台帳・相場で計算と候補保存ができます（画面上部に「オフライン」と表示）。外部検索・最新相場は使えません。アプリを更新したら、オンラインで一度開き直してください。

## 画面

下部メニュー：**スキャン／候補／商品／在庫／その他**

- **スキャン**：背面カメラでJAN/EAN-13・EAN-8・UPC-Aを読み取り、原コードと正規化コードを別々に保存（先頭ゼロは維持）、チェックデジットを検証。未登録なら「商品未登録」と出し、価格や商品名は出しません。候補が複数なら選択画面。店舗独自コード（20〜29始まり等）は店名との紐づけが必須。カメラが使えないときは、写真から読み取るか手入力・型番検索。読み取ったらカメラを止め、画面を離れたときも止めます。
- **候補**：判定（判定できない／見送り／条件付き／仕入れ候補）を色と文字で表示。予想残額（標準・慎重）、仕入れ上限、判定理由、内訳、レート・手数料プロファイルの版、送料の根拠、相場の確認日。入力途中の内容は自動保存されます。「この見積もりを保存」で、その時点の入力と根拠を変更できない形で残します。
- **商品**：台帳（日本語名・英語名・型番・地域・版など）、バーコード、成約例の手動登録（採用・除外とその理由）、同じ状態の成約例だけで出す統計（少数・重複・外れ値・送料不明・古さの注意つき）。
- **在庫**：候補→購入済→検品中→出品準備→出品中→売却→発送→完了。状態の変更・売却・返品・返金・キャンセル・処分はすべて履歴として残り、上書きしません。予想残額と実績残額は別に表示します。
- **その他**：探し物リクエスト、設定、手数料プロファイル、送料見積、為替レート、バックアップ・復元・CSV出力、ゴミ箱、このアプリについて（架空デモ商品の追加）。

## Phase 2（追加機能）

### ネットで調べる
スキャン結果と商品画面に「ネットで調べる」を追加しました。
- 中継サーバー（`worker/`）を設定すると、Yahoo!ショッピング（JAN→商品名・国内価格）と eBay Browse API（出品中の価格・件数）を自動検索します。設定方法は `worker/README.md`
- eBay の出品価格は「出品中の参考価格」として保存でき、成約の統計には入りません
- eBay売却済み・ヤフオク落札相場・メルカリ・Amazon・Google の検索リンクは、設定なしで使えます

### 定期リサーチ（蓄積）
- `public/research/index.json` に売れ筋候補を蓄積し、アプリの「その他 → 定期リサーチ」で表示します
- 週1回の定期タスクが `research/RUNBOOK.md` の手順で更新し、公開サイトへ反映します（`scripts/deploy-pages.sh`）
- 候補は記事・価格ガイド・出品例からの「調べる候補」で、売れる保証ではありません

### 複数サイトの取り込み（追加仕様書 v1 の 1〜3 段階）
- 「その他 → 取り込みデータ」：出品中／成約／入札中／カタログ／SNS話題を分けて保存する共通レコード（`sourceRecords`、DBスキーマ v2）
- 手動取り込み（URL＋本文＋価格）と CSV 取り込み（列の対応づけ・プレビュー・重複確認）
- URL は追跡パラメーターを除いて正規化し、「サイト＋商品ID」で重複を除く。価格が変わったら履歴に追加（件数は増えない）
- 商品との照合（一致確認済／一致候補／不一致／未特定）と、箱のみ・ジャンク・別地域・まとめ売り・限定版・非純正の警告
- 一致確認済み・状態入力済みの**成約**だけを「成約例として採用」でき、既存の相場統計と利益計算に入る（独自の計算は追加していない）
- 「その他 → 接続状態・データ取得検証表」：サービスごとの取得方式と状態（`docs/data-source-verification.md`）
- 未実装：ジョブ実行管理・費用上限・通知・X/YouTube の API 接続（仕様書 14章の 4〜8）

## 計算の定義

```
予想残額 E = (P + S) × r − F − C − D − A − R − I − K − U − Q
```
- 「利益」ではなく **予想残額（作業代・固定費・所得税等の控除前、予備費控除後）** と表示します。消費税還付は足しません。
- 徴収税 T は売上に足しません。手数料の課金対象に設定されている場合だけ手数料が変わります。T が不明なら概算と表示します。
- 為替費用は「レートに織り込む」か「別計上する」のどちらか一方だけが適用されます（二重計上しません）。
- 手数料は確認日・版つきのプロファイル（料率＋固定額、送料や税を課金対象に含めるか）か、手入力（概算/実額）。**料率の初期値は入れていません**。自分の条件を eBay の公式ページで確認して登録してください。
- 仕入れ上限 Cmax は同じ計算関数で目標 M を満たす最大の C を求めます（仕入れ値に比例する費用にも対応）。負の値なら「無料でも目標未達」と表示します。
- 利益率 = E ÷ ((P+S)×r)。分母が0なら算出しません。
- 空欄（未入力）と 0 は区別します。0 は「0で確定」ボタンで明示的に入れます。未入力があれば判定できません。
- 慎重シナリオ：売価−10%、円高5%、国際送料+15%（仮設定・設定で編集可）。料率型の手数料は自動で再計算されます。
- 実績残額：入金（控除後入金なら手数料は再控除しない）− 返金 − 実費。予備費は含めません。

### 判定（優先順）
1. **判定できない**：商品同定が未確定、必須項目が未入力、配送可否が未確認、または目標未設定（計算のみ表示）
2. **見送り**：標準の残額が目標未満、配送不可、確定した取扱不可理由、1点上限超過
3. **条件付き**：慎重では目標未達、状態不明、未確認のチェック項目、成約例が少数（5件未満）、相場が古い（30日超）、手数料が概算
4. **仕入れ候補**：上記すべてを満たした場合

これらの基準値は仮設定です。需要や利益を保証するものではありません。

## バックアップ・復元

- 「その他 → バックアップ」で JSON を書き出します（スキーマ版つき。全データ・ゴミ箱内・設定を含む）。最終バックアップ日を表示し、7日以上空くと警告します。
- 復元は「その他 → バックアップ → 復元」でファイルを選びます。**現在の端末内データはバックアップの内容で置き換わります。**
- データは**このブラウザの中だけ**に保存されます。ブラウザのデータ（履歴・Webサイトデータ）を消すと消えます。iPhone Safari は長期間開かないサイトのデータを削除することがあるため、定期的なバックアップをおすすめします。ホーム画面に追加して使うと消えにくくなります。
- スマホとPCの自動同期はありません。端末を移すときは、書き出したファイルを移動先で復元してください。
- CSV出力は表計算ソフト向けです（BOM付きUTF-8。数式として解釈される文字で始まる値は無害化）。

## 運用費用が発生する条件

- このアプリ自体：無料（外部API・AIを呼びません）。
- 発生し得るもの：HTTPS ホスティングを有料プランにした場合、独自ドメイン、将来 Phase 2 で AI 接続をした場合の API 料金（開発用の Claude Code とは別料金）。

## 既知の制限・未確認事項

- iPhone 実機でのカメラ読み取りは未確認です（テスト14）。暗所・反射・小さなバーコードでは読み取りにくいことがあります。
- 商品画像・参考画像の添付画面は未実装です（データの入れ物とバックアップは対応済み）。
- 統計の通貨が混ざった場合は、多い方の通貨だけを使い、他は除外します（換算はしません）。
- 手数料・送料・為替レートはすべて手入力です。eBay の料率は変わるため、確認日を記録して定期的に見直してください。
- 中古品の仕入れ販売に必要な古物商許可などの法令面は、このアプリでは確認できません。開始前に別途確認してください。
